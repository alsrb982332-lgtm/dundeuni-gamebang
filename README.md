# 🦕 든든이 게임방 — 부모용 설명서

형제를 위한 교육 게임 6개를 **앱 하나**로 묶었어요. 태블릿 홈 화면 아이콘 하나로 열고, 인터넷이 없어도 돼요.
PC에서 고쳐서 올리면(배포) 태블릿에 자동으로 반영돼요.

- 주소: **https://alsrb982332-lgtm.github.io/dundeuni-gamebang/**
- 게임: 든든 공룡나라 · 따라 쓰기 놀이 · 든든 블록 놀이 · 마음 날씨 · 형아랑 같이 · 반짝반짝 습관 놀이

---

## 1. 처음 한 번: GitHub 준비 (이미 했으면 건너뛰기)

1. https://github.com 에서 가입 → 오른쪽 위 **+** → **New repository** → 이름 `dundeuni-gamebang`, **Public** → **Create repository**
2. 저장소 → **Settings** → 왼쪽 **Pages** → **Source** 를 **GitHub Actions** 로
3. PC에서 올릴 권한 주기 (자동 배포 파일을 올리려면 `workflow` 권한이 필요해요). VS Code 터미널에서:
   ```
   gh auth refresh -h github.com -s workflow
   gh auth setup-git
   ```
   브라우저가 열리면 코드를 넣고 **Authorize** 를 눌러요.

## 2. 태블릿에 설치하기 (홈 화면에 추가)

- **안드로이드 (Chrome)**: 주소를 연 뒤 오른쪽 위 **⋮** → **「홈 화면에 추가」** 또는 **「앱 설치」**
- **아이패드 (Safari)**: 주소를 연 뒤 **공유 버튼(□↑)** → **「홈 화면에 추가」**

홈 화면의 든든이 아이콘으로 열면 주소창 없이 전체 화면으로 떠요. 한 번 연 뒤에는 **비행기 모드에서도** 게임 6개가 모두 돼요.

## 3. 화면 고정 (아이가 게임방 밖으로 못 나가게)

게임방 → 오른쪽 위 ⚙️ → 어른 확인(덧셈) → **「화면 고정 설정 방법 보기」** 에 그림으로 나와요.

- **안드로이드 「앱 고정」**: 설정 → 보안 및 개인정보 보호 → 기타 보안 설정 → **앱 고정** 켜기, 「고정 해제 전 잠금 화면 열기」도 켜기 → 게임방을 연 상태에서 **최근 앱 버튼** → 게임방 아이콘 → **「이 앱 고정」**. 풀 때는 **뒤로 + 최근 앱을 동시에 길게**.
- **아이패드 「사용법 유도」**: 설정 → 손쉬운 사용 → **사용법 유도** 켜기, 암호 설정 → 게임방을 연 상태에서 **상단(또는 홈) 버튼 3번** → 시작. 풀 때는 같은 버튼 3번 → 암호 → 종료.

(OS 버전에 따라 메뉴 이름이 조금 다를 수 있어요.)

## 4. 어른 설정 (게임방 메인 오른쪽 위 ⚙️ → 덧셈 답)

아이 이름(이 태블릿에만 저장) · 아바타 · 하루 놀이 시간 · 쉬는 시간 알림 · 소리 크기 · 게임 켜고 끄기 ·
엄마·아빠 목소리 녹음(이 태블릿에만 저장) · 기록 내보내기/가져오기 · 화면 고정 안내 · 버전

> 아이 실명·사진·목소리는 **코드나 저장소에 넣지 않아요.** 이름과 녹음은 태블릿 안에만 있어요.

## 5. 고치고 배포하기

1. VS Code 에서 수정 (또는 Claude Code 에게 부탁)
2. Claude Code 에게 **"배포해 줘"** 라고 하거나, 터미널에서 `git push`
3. 2~3분 뒤 자동 배포 (GitHub 저장소 → **Actions** 탭에서 진행 상황 확인)
4. 태블릿에서 게임방을 **완전히 닫았다가 다시 열면** 새 버전 (게임 중에는 새로고침되지 않고, 게임방 메인에 있을 때 조용히 바뀌어요)

### 컴퓨터·태블릿에서 미리 해 보기

```
npm install             (처음 한 번)
npm run dev             (컴퓨터 브라우저에서 http://localhost:5173)
npm run dev -- --host   (같은 와이파이의 태블릿에서: 터미널에 나온 Network 주소를 태블릿 브라우저에 입력)
npm test                (자동 시험)
npm run build           (배포용 파일 만들기)
```

## 6. 새 게임 추가하기

`src/games/registry.ts` 의 `GAMES` 목록에 **한 줄** 추가하면 메인 화면에 나와요.

```ts
{ id: 'my-game', name: '새 게임', color: '#88CCEE', kind: 'legacy', src: 'legacy/my-game/index.html' },
```

- HTML 파일 하나짜리 게임은 `public/legacy/my-game/index.html` 에 넣어요.
- 카드 그림은 `src/shared/art/svg.ts` 의 `GAME_ART` 에 같은 id 로 추가해요 (없으면 든든이 그림).

## 7. 상황·습관 데이터 추가

**마음 날씨 상황** — `src/games/maeum-nalssi/data/situations.json` 에 하나 추가하면 코드 수정 없이 게임에 나와요.

```json
{
  "id": 16,
  "modes": ["dong", "hyeong"],
  "story": "{동생가} 비눗방울을 잡았어!",
  "emotion": "happy",
  "friend": "동생",
  "bg": "park",
  "props": [{ "e": "🫧", "x": 64, "y": 40, "anim": "float" }],
  "actions": [
    { "icon": "👏", "label": "박수 쳐 주기", "good": true, "reply": "{동생가} 활짝 웃었어!" },
    { "icon": "🙈", "label": "모른 척하기", "good": false }
  ]
}
```

- `modes`: `"dong"`(동생 모드) / `"hyeong"`(형 모드). 동생 모드는 `happy`·`sad` 만 나와요.
- `emotion`: happy 기뻐요 · sad 슬퍼요 · angry 화나요 · scared 무서워요 · surprised 놀라요 · upset 속상해요
- `friend`: `형` · `동생`(설정한 아바타로 그려짐) 또는 bear · bunny · chick · cat · puppy
- 이름 자리표시자: `{형}` `{동생}` — 조사는 `{형이}` `{동생가}` 처럼 쓰면 이름에 맞춰 바뀌어요.

**생활 습관(반짝반짝 습관 놀이)** — 아직 1단계(그대로 넣기)라서 원본 `legacy/banjjak-habits/src/data/habits.json` 을 고친 뒤 `npm run legacy` 로 복사본을 다시 만들어요. (2단계로 옮기면 `src/games/banjjak-habits/data/` 에서 바로 고치게 돼요)

## 8. 문제가 생겼을 때

| 증상 | 해결 |
|---|---|
| 태블릿에서 새 버전이 안 보여요 | 게임방을 **완전히 닫고**(최근 앱에서 위로 밀기) 다시 열기. 그래도 안 되면 한 번 더 |
| 소리가 안 나요 | ⚙️ → 「소리 점검하기」. 기기 무음 모드·음량 확인. 한국어 TTS 가 없으면 기기 설정에서 내려받기 |
| 태블릿을 바꿔요 | 옛 태블릿 ⚙️ → **기록 내보내기**(JSON 파일) → 새 태블릿으로 옮겨서 ⚙️ → **기록 가져오기** (녹음은 다시) |
| 「든든이가 졸려요」에서 안 넘어가요 | 오늘 놀이 시간이 끝난 거예요. 오른쪽 아래 「🔓 어른」 → 덧셈 → 10분 더 / 오늘은 제한 없이 |
| 배포가 안 돼요 | GitHub 저장소 **Actions** 탭에서 빨간 ✗ 를 눌러 오류 확인 → Claude Code 에게 보여 주기 |
